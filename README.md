# BUSTED UP!（バステッド・アップ）

> inspired by Tally Up（Eric Olsen）

地下の違法カジノを舞台に、警察の摘発が入る前に「勝ち逃げ」を狙う、CPU対戦のダイスゲーム。
ブラウザだけで動く静的サイト（サーバーなし）。

## 遊び方（要約）
- 胴元が6つの賭場ダイスから3つを選んで振る。**チップの目**は席に残っている全員のチップに、**供託の目**はテーブル中央の供託に入る。
- サイレン2つ以上で**摘発**：席に残っていた全員のチップと供託が没収。
- ◎付きの目で胴元ダイス（追加で振る／ご祝儀 供託+100／ショバ代 供託−100／ハイローラー 供託×2）。振る前に去就を宣言でき、追加で振るダイスは胴元が選ぶ。
- 振るたびに全員が同時に「残る／立つ」を宣言。立つとチップと供託の取り分を金庫へ。
- **供託の山分け（独自ルール）**：同時に立った人数で供託を山分け（10点単位で切り捨て、端数は供託に残る）。全員が立ったら端数は消える。
- ラウンド終了時に誰かの金庫が目標額に届いたら、金庫が最も多い人の勝ち。

詳しくは [要件定義書.md](要件定義書.md) とゲーム内の「遊び方」。

## 開発

```bash
npm install
npm run dev      # 開発サーバー
npm test         # ルールの単体テスト
npm run build    # 本番ビルド（dist/）
npx tsx scripts/simulate.ts <CPU人数> <局数> <強さ>   # CPU同士の対戦シミュレーション
```

- 開発時、または URL に `?debug` を付けると「一手戻る」ボタンが出る。

## 構成

| パス | 内容 |
| --- | --- |
| `src/game/types.ts` | 型と定数（胴元ダイスの増減額、山分けの単位など） |
| `src/game/dice.ts` | 賭場ダイス6種と胴元ダイスの出目 |
| `src/game/engine.ts` | ルール（純粋関数）：開帳・振る・宣言・ラウンド進行 |
| `src/game/odds.ts` | 1回振ったときの結果の確率の列挙、期待値・最適停止の計算 |
| `src/game/cpu.ts` | CPUの思考（強さ3段階、性格3種） |
| `src/game/store.ts` | ゲーム進行と演出のタイミング（Zustand） |
| `src/components/` | 画面（席、テーブル、ダイス、モーダル、摘発演出） |
| `scripts/simulate.ts` | CPU同士の対戦シミュレーション |
