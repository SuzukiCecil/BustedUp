### 分かったこと
- **胴元と客の差はほぼない**（胴元と客の違いはダイスを選ぶことだけになったため）。
- **1局が長すぎる**：1人あたり1ラウンドの獲得が80〜130点しかなく、目標3000では22〜29ラウンドかかる。
- **すぐ席を立つ**：1ラウンドの振りは平均2〜3回。供託は先に立った人が取るので、早く立つほうが得になっている。
- **摘発が多い**：47〜89%。サイレン3面のダイスがあり、サイレン3つも摘発になったため。
- **同じ判断をする席は損をする**：つよいの「あなた」とジャック（同じ性格、判断にばらつきなし）は常に同時に立って山分けになり、3人ではマダムが60局中54局、4人ではマダムとボスが全勝。供託ルールが「読まれやすい動き」を強く罰することを示している。逆に言えば、人間がCPUの動きを読めると一方的に勝てるおそれがある。

## 1ラウンドで目標点に届く確率（`npx tsx scripts/oneRound.ts 20000`）

降りずに振り続け、届いた時点で立つとした場合。賭場ダイス20通りそれぞれ2万回。追加ダイスは胴元が摘発されにくいものを選ぶとする。

| 目標 | 供託込み・平均 | 供託込み・最良（丁半+ルーレット+BJ） | チップのみ・平均 |
| --- | --- | --- | --- |
| 1000 | 12.4% | 18.8%（約6回で到達） | 0.09% |
| 1500 | 6.3% | 10.7%（約8回） | 0.00% |
| 2000 | 3.7% | 7.2%（約9回） | 0.00% |

- 供託込みは「供託を1人で受け取れる」最良の場合。他の人が先に立てば供託を持っていかれるので、実際はこれより低い。
- 1ラウンドで届くのは供託（特にハイローラー×2）頼み。チップだけではほぼ届かない。

## ダイスの強さの偏り（`npx tsx scripts/diceBalance.ts <案> [--detail]`、案は `scripts/diceVariants.ts`）

状況ごと（1人で最適に立つ／4人卓で供託を持っていかれうる／1ラウンドで400点・800点に届く確率）に組み合わせ20通りを並べ、各ダイスが上位5組に入るかを見る。

| 案 | 内容 | 最良/最悪の比（1人・4人・逆転400・逆転800） | 上位5組に入らない状況 |
| --- | --- | --- | --- |
| current | 現行 | 1.60 / 1.21 / 1.66 / 2.37 | なし。ただしスロットはほぼ全状況で最弱、ルーレットが常に最強 |
| A | ルーレットを丁半並み、標準・危険を上げる | 1.31 / 1.18 / 1.29 / 1.56 | 闘犬（4人） |
| A2 | Aより危険を上げる | 1.24 / 1.32 / 1.17 / 1.32 | ブラックジャック（逆転400） |
| B | A2の標準を上げる | 1.21 / 1.27 / 1.21 / 1.31 | スロット（1人）、闘犬（4人） |
| B2 | Bの安定を下げる | 1.16 / 1.30 / 1.19 / 1.26 | スロット（1人）、闘犬（4人）※役割の住み分け |

- 現行は「危険なダイスを選ぶ理由がない」：大差で負けていて一発逆転が欲しい場面でも、安定2個の組が最善。
- B2：ダイスごとの平均価値の差が3%程度に収まる。スロット（チップ型）は4人卓で最強、闘犬（供託型）は1人で最強と、チップ型と供託型で得意な状況が分かれる。
- どの案でも最良の組は「安定2個＋1個」になりやすい（サイレン2つで摘発のため、サイレン1面のダイス2個は摘発率が低い）。

- 1個を下げると、別の1個が独占する「もぐらたたき」になる。机上の比較（`diceBalance.ts`）とCPUの選び方は一致しない（CPUは1〜2回で立つ前提で選ぶ）。

- Eがいちばん近い：2人のつよいでは安定、4人ではスロット、2人のふつうでは闘犬が多く、状況で最善が変わる。ただしポーカーが弱い（0.09〜0.37）。
